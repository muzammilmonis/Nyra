# NYRA Data Deletion Instructions

**Effective Date: August 3, 2026**

NYRA users and server administrators may request deletion of eligible information associated with their Discord account or Discord server.

## 1. Information That May Be Deleted

Depending on NYRA's current features and stored records, a deletion request may cover:

* User profile biography
* Liked or saved songs
* Music-source preferences
* Recently played music information
* User-specific command settings
* Giveaway participation records
* Invite-tracking information
* Server configuration
* AutoMod configuration
* Autorole configuration
* Command permissions
* Other information associated with a Discord user ID or server ID

Some temporary information may automatically disappear when NYRA restarts or when the information is replaced.

## 2. How to Request Deletion

Submit a request through one of the following official channels:

* **NYRA Support Server:** YOUR_SUPPORT_SERVER_URL
* **Contact Email:** YOUR_CONTACT_EMAIL

Your request should include:

* Whether the request concerns a user or server
* Your Discord user ID
* The affected Discord server ID, where applicable
* A brief description of the information you want removed

Do not include your Discord password, account token, bot token, API keys or other credentials.

## 3. Identity and Authorization Verification

NYRA may require reasonable verification before processing a deletion request.

For user data, verification may require confirmation that the requester controls the relevant Discord account.

For server data, verification may require confirmation that the requester is the server owner or has sufficient administrative authority.

This verification helps prevent unauthorized deletion requests.

## 4. Processing the Request

After a valid request is received and verified, eligible information will be located and removed from NYRA's active storage where reasonably possible.

Information may remain temporarily in:

* Restricted backups
* Security records
* Abuse-prevention records
* Discord messages or logging channels controlled by server administrators
* Third-party services operating under their own policies

Backup copies will normally be removed through the standard backup-retention cycle rather than immediately altered.

## 5. Information Controlled by Discord Servers

NYRA may post moderation logs, AutoMod notices, invite information or command logs directly into Discord channels selected by server administrators.

Messages stored inside those channels are controlled by the applicable Discord server.

Users should contact the server owner or administrators to request removal of those Discord messages.

## 6. Information We May Retain

Limited information may be retained where reasonably necessary to:

* Prevent fraud, abuse or security threats
* Enforce NYRA's Terms of Service
* Investigate technical or moderation incidents
* Resolve disputes
* Meet legal obligations
* Protect NYRA, its operators, users or third parties

Information retained for these purposes will be limited to what is reasonably necessary.

## 7. Removing NYRA From a Server

Removing NYRA from a Discord server stops the Bot from processing new activity in that server.

Removal may automatically delete some server-specific records, but it may not immediately delete every existing record.

Server owners may submit a separate deletion request using the process described above.
