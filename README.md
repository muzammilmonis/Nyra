## About NYRA

**NYRA** is a Discord bot that provides music, moderation, utility, profile, giveaway, invite-tracking and community-management features.

This repository contains NYRA's official public policies. It does not contain NYRA's source code, private configuration, credentials or internal infrastructure.

## Privacy Summary

NYRA may process limited information required to provide its features, including:

* Discord user and server IDs
* Server configuration
* Commands and command arguments
* Music searches and playback information
* Liked songs and recently played tracks
* User profile information voluntarily provided to NYRA
* Invite-tracking information
* Giveaway participation
* Moderation and AutoMod information

NYRA does not sell user information.

For complete details, read the [Privacy Policy](./PRIVACY.md).

## Third-Party Services

NYRA may rely on third-party platforms and services, including Discord and supported music, lyrics, metadata or hosting providers.

Third-party services operate under their own policies and terms.

NYRA does not own or host music, lyrics, artwork or other third-party media content made available through supported providers.
