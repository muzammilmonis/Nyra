## 🌸・About NYRA

<table>
<tr>
<td width="65%">

**NYRA** is a cute, modern and feature-rich Discord bot designed to make communities more enjoyable, organized and engaging.

NYRA provides features such as:

* 🎵 High-quality music playback
* 🛡️ Moderation and AutoMod
* 🎉 Giveaways
* 👤 User profiles
* 🔗 Invite tracking
* ⚙️ Community-management utilities

## 🔐・Privacy at a Glance

NYRA may process limited information required to operate its features.

| Category                | Examples                                                   |
| :---------------------- | :--------------------------------------------------------- |
| 👤 Discord information  | User IDs, server IDs, channel IDs and role IDs             |
| ⚙️ Server configuration | Prefixes, AutoMod settings and enabled features            |
| 🎵 Music activity       | Searches, liked songs and recently played tracks           |
| 💬 Commands             | Command names, arguments and required interaction data     |
| 🎉 Giveaways            | Participant IDs and giveaway configuration                 |
| 🔗 Invite tracking      | Invite codes, inviter IDs and join information             |
| 🛡️ Moderation          | Warnings, configured actions and AutoMod violations        |
| 🌸 Profiles             | Voluntarily submitted biography and preference information |

## 🌐・Third-Party Services

NYRA may rely on external platforms and service providers to deliver certain features.

These may include:

* 💬 Discord
* 🎵 Music and media providers
* 📝 Lyrics and metadata providers
* 🎧 Lavalink infrastructure
* ☁️ Hosting and database infrastructure

Third-party providers operate according to their own policies, terms and availability.

> [!NOTE]
> NYRA does not claim ownership of music, lyrics, artwork, videos or other third-party media made available through supported services.
